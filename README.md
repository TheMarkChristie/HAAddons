# Mark Christie's Home Assistant add-ons

Add this repository in Home Assistant: Settings > Add-ons > Add-on store > the three-dots menu > Repositories, paste
`https://github.com/TheMarkChristie/HAAddons`, Add. The add-ons below then appear in the store.

| Add-on | What it is |
| --- | --- |
| [Shortlist](shortlist/) | Per-person recommendation rows on Plex Home from watch history, by Steven Adams ([stevezau/shortlist](https://github.com/stevezau/shortlist), MIT). This add-on wraps the published image; nothing is built or changed here. Pairs with the [Plex Picks](https://github.com/TheMarkChristie/HAPlexPicks) integration, which shows the rows in Home Assistant. |

Each add-on's own page has the documentation (the Documentation tab in Home Assistant, or `DOCS.md` here).
